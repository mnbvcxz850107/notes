一、骨頭是活的城

故事

你以為骨城是一座石頭堆的死城。走近才發現不是——城牆裡有水管，有巡邏員，晚上還有工班在敲敲打打。

城裡有三種人。砌牆工負責倒水泥、把牆疊高；拆除隊負責把老舊的牆敲掉；還有住戶，他們原本也是砌牆工，倒水泥的時候不小心把自己封進了牆裡，從此住在牆的小空腔中，靠細細的通道跟外面聯絡，變成城裡最靈敏的感測器——哪面牆被壓、哪面牆要裂，他們最先知道。

關鍵在這裡：被封進牆裡的是人，硬掉的是水泥。砌牆工先把水泥漿倒出去，水泥漿在體外慢慢結晶變硬。人沒有變成石頭，人只是住在石頭裡面。這句話你先記著，第一題就考它。

回到現實

砌牆工是 osteoblast（成骨細胞），拆除隊是 osteoclast（破骨細胞），住戶是 osteocyte（骨細胞）。osteocyte 就是被自己分泌的基質包埋起來的 osteoblast，住在 lacuna（骨小腔）裡，靠 canaliculi（骨小管）互相連通，負責感知力學訊號。

水泥漿是 osteoid（類骨質），主要成分是 type I collagen。它被分泌到細胞外之後才礦化，礦物質是 hydroxyapatite（氫氧磷灰石，Ca₁₀(PO₄)₆(OH)₂），不是純鈣。骨頭因此不是惰性的石頭，而是有血管、有代謝活性、持續 remodeling 的活組織。

拆除隊的出身跟另外兩者不同：osteoblast 與 osteocyte 來自間質幹細胞（mesenchymal）系統，而 osteoclast 來自單核球／巨噬細胞系（monocyte），由多個前驅細胞融合成多核細胞。這個「出身不同」是考點。

本章最容易被扣分的一句話：「骨頭是由鈣化的細胞構成的」——錯。細胞不會鈣化，鈣化的是細胞分泌到外面的 osteoid。

二、兩種砌法，一間工務所

故事

城裡的牆有兩種砌法。急著擋住缺口的時候，工班亂中有序地把磚往上堆，纖維交錯亂搭——快，但不整齊。等到不趕時間了，他們會把亂牆拆掉重砌，這次一層一層平行疊上去，像書頁一樣。成年的骨城，牆面幾乎都是後面這種。

城牆外面還有一間永遠亮著燈的工務所。裡面坐著一群還沒分派工作的學徒。城牆哪裡破了，學徒就從這裡被叫出去，臨時受訓成砌牆工趕過去補。工務所不是儲藏室，也不是拆除隊的辦公室——它是人力來源。

回到現實

亂砌的是 woven bone（編織骨）：collagen 纖維隨機交織，出現在胎兒骨、骨折癒合早期、快速生長處。整齊疊層的是 lamellar bone（板層骨）：collagen 纖維平行排列成層，是所有成熟骨的組成方式。

這裡有個很多人混淆的層次問題：lamellar 是「排列方式」，compact 與 trabecular 是「巨觀結構」。Compact bone 由同心圓排列的骨板（osteon／哈維氏系統）構成，trabecular bone 是不規則網狀的骨小梁——但兩者的骨質本身都是 lamellar。所以問「平行層狀且存在於所有成熟骨」時，答案是 lamellar，不是 compact。

工務所是 periosteum（骨膜）。它的內層又叫 cambium layer，含 osteoprogenitor cells（骨原前驅細胞），可分化為 osteoblast，所以骨膜的主要功能是骨的生長與修復，不是儲脂、不是肌肉收縮、也不是給破骨細胞當錨點。

三、建城的兩條路：膜內骨化與軟骨內骨化

故事

骨城不是一夜之間長出來的。開拓時有兩種完全不同的做法。

第一條路很直接：一群新人在空地上聚集，就地受訓成砌牆工，直接開始倒水泥。沒有鷹架、沒有模板，牆就從一片結締組織薄膜裡長出來。這叫「就地起牆」。

第二條路繞了一圈：先請軟墊師傅用軟骨做一個等比例的模型，形狀先擺在那裡。等模型長到夠大，從模型正中央開始鈣化，血管挖通道進來，工班沿著通道進駐，把中央的軟骨換成真骨——這是初級骨化中心。之後血管再往兩端的骨骺伸過去，形成次級骨化中心。中間留一條沒換掉的軟骨帶，就是生長板。

兩條路都會經過一段「水泥還沒乾」的亂砌期，最後才整修成整齊的板層牆。

回到現實

Intramembranous ossification（膜內骨化）：從纖維結締組織膜直接成骨，見於顱骨扁平骨、鎖骨。順序是 mesenchymal cells 聚集 → 分化為 osteoprogenitor cells → 再分化為 osteoblasts（形成骨化中心）→ 分泌 osteoid → osteoid 鈣化形成 woven bone → 改建為 compact bone。

Endochondral ossification（軟骨內骨化）：先形成 hyaline cartilage（透明軟骨）模型，見於大部分長骨。順序是軟骨模型形成 → chondrocyte 增生、肥大 → 基質鈣化 → 血管侵入（periosteal bud）→ 初級骨化中心（從中央開始）→ 血管延伸至骨骺形成次級骨化中心。

兩個高頻陷阱：

① 膜內骨化的來源是纖維結締組織膜，不是 fibrocartilage（纖維軟骨）。名字裡有 fibro 就選它，是最常見的誤答。

② 軟骨內骨化的鈣化從中央開始，不是從兩端開始。兩端（骨骺）是後來才有的次級骨化中心。

③ mesenchymal cells 不會直接變成 osteocytes，中間要經過 osteoprogenitor → osteoblast，osteocyte 是 osteoblast 被埋起來之後的最終型態。

四、拆與蓋的循環：ARF 與它的補給線

故事

骨城最反直覺的一條規矩是：永遠是拆除隊先動工。

流程固定成一套四拍。第一拍，有人吹哨把拆除隊叫醒；第二拍，拆除隊把那段舊牆啃掉，留下一個坑；第三拍是交接，拆除隊撤走，砌牆工進場清點；第四拍，砌牆工把坑填回去。四拍走完，那段牆就換新了。

而工班要幹活得有補給。維生素 C 是水泥的黏著劑——沒有它，膠原蛋白根本合不起來，牆會鬆散。維生素 A、D、B12、錳、鎂各有各的角色。副甲狀腺素則是那個吹哨子的人，喊太多次，拆除隊就會過勞加班，牆愈拆愈薄。

唯一在名單上顯得不重要的是鉀。它管的是別的城務，跟砌牆這條線關係最小。

回到現實

骨重塑循環叫 ARF cycle，順序固定為 Activation → Resorption → Reversal → Formation：破骨細胞活化 → 破骨細胞吸收骨質 → 逆轉期（成骨細胞接手）→ 成骨細胞形成新骨。

影響因子：Vitamin C 催化 collagen 合成（羥化脯胺酸所需），缺乏導致骨膠原合成下降；Vitamin A、D、B12 以及錳、鎂都對重塑有影響；PTH 過多促進骨吸收。鉀對骨重塑的影響相對最小，是題目設定的「較不相關」答案。

五、軟墊區：軟骨

故事

骨城的關節處鋪著一層軟墊。做軟墊的師傅跟砌牆工是同鄉——都是那批沒分派工作的新人出身，只是走了不同的路。

軟墊區有一條奇怪的規矩：不准鋪水管。整個軟墊區沒有一條血管，養分得從邊緣慢慢滲進來。代價是這裡出事修不快，成年之後幾乎補不回來。

師傅分兩級。年輕的學徒師傅還在外圍走動、還會分裂；等他被自己鋪出來的墊料包在中間、動不了了，就升格成坐鎮師傅——但他沒有退休，坐在裡面照樣繼續生產墊料。這點跟骨城不一樣：骨城裡被封進牆裡的住戶不再砌牆，軟墊區裡被包住的師傅還在做工。

軟墊有三種材質。透明墊最常見，鋪在肋骨末端、關節面、生長板；纖維墊最耐壓，塞在椎間盤；彈性墊最會回彈，用在耳朵和會厭。

回到現實

軟骨細胞與骨細胞同樣源自 mesenchymal cells。Chondroblast（軟骨母細胞）可由間質細胞分化，也可由 perichondrium（軟骨膜）分化而來；當它被自己分泌的細胞外基質包圍，就成為 chondrocyte（軟骨細胞）。關鍵：chondrocyte 仍然會製造細胞外基質，不是只有 chondroblast 會。

軟骨無血管（avascular），養分靠基質擴散，因此成年後再生能力差。

三型分布：Hyaline（透明軟骨）＝肋軟骨末端、關節軟骨、生長板、氣管；Fibrocartilage（纖維軟骨）＝椎間盤、恥骨聯合、半月板，以 type I collagen 為主且無軟骨膜；Elastic（彈性軟骨）＝外耳、會厭，富含彈性纖維。

六、在實驗室裡把城弄壞

故事

要研究骨城怎麼垮，得先想辦法讓它垮。研究員手上有三種合法手段：灌類固醇讓砌牆工士氣低落；拿掉卵巢切斷保護荷爾蒙的供應；直接改基因，讓城裡天生就少一種工人。

但你不能拿槌子把牆敲斷再接回去——那是製造骨折，不是製造骨質疏鬆。前者是局部外傷，後者是全身性的骨量流失，是兩件事。

城垮了之後怎麼量？兩種測法很像但問的不同。轉輪看老鼠能在轉動的棒子上撐多久，測的是協調；抓握看牠前肢抓不抓得牢，測的是肌力。

回到現實

骨質疏鬆動物模式的常見誘發方式：注射 glucocorticoids、雌鼠 ovariectomy（去卵巢，模擬停經後骨鬆）、基因改造。「把骨頭打斷再接回去」屬於骨折模型，講義未列為骨鬆誘發法。

功能評估：Rota-rod test 測 motor coordination（動作協調、小腦與平衡），指標是 latency to fall；Grip strength test 測 muscle strength 與 neuromuscular function，主要測前肢，指標是掉落比例。

七、考前速記

  • 細胞不會鈣化，鈣化的是分泌到細胞外的 osteoid；礦物是 hydroxyapatite，不是純鈣。
  • osteoblast／osteocyte 出自間質系統，osteoclast 出自 monocyte。
  • 分化鏈：mesenchymal → osteoprogenitor → osteoblast → osteocyte，不可跳級、不可逆向。
  • Woven＝纖維隨機（未成熟、骨折早期）；Lamellar＝纖維平行成層（所有成熟骨）。compact／trabecular 是巨觀結構，兩者骨質都是 lamellar。
  • Periosteum 的主功能＝骨的生長與修復，因為 cambium layer 藏著 osteoprogenitor。
  • 膜內骨化來自纖維結締組織膜（不是 fibrocartilage）；軟骨內骨化來自 hyaline cartilage。
  • 軟骨內骨化從中央開始鈣化 → 初級骨化中心；骨骺的是次級骨化中心。血管一定最後才進來。
  • ARF＝Activation → Resorption → Reversal → Formation。永遠先拆後蓋；A 指的是破骨細胞活化。
  • 骨重塑影響因子：維生素 A、B12、C、D ＋ 錳、鎂 ＋ PTH 有影響；鉀影響最小。Vitamin C 專管 collagen 合成。
  • 軟骨無血管，養分靠擴散，成年後修復差。
  • chondrocyte 被包埋後仍會分泌基質——與骨細胞不同，考「Only chondroblasts…」必錯。
  • 三型分布：hyaline＝肋末端／關節／生長板／氣管；fibrocartilage＝椎間盤／恥骨聯合／半月板、type I 為主、無軟骨膜；elastic＝外耳、會厭。
  • 骨鬆動物模式＝類固醇／去卵巢／基因改造；打斷骨頭是骨折模型，不是骨鬆。
  • Rota-rod＝協調（latency to fall）；Grip strength＝肌力與神經肌肉功能（前肢）。

八、單字表

osteoid
oste-（骨）+ -oid（像…的）　類骨質。骨的未礦化有機基質，主成分 type I collagen。
記憶提示

「像骨但還不是骨」＝還沒乾的水泥。細胞先分泌它，它才在細胞外鈣化。

osteoblast
oste-（骨）+ -blast（生芽、造者）　成骨細胞。分泌 osteoid 並促進礦化。
記憶提示

-blast 一律是「製造者」：chondroblast 造軟骨、fibroblast 造纖維。

osteocyte
oste-（骨）+ -cyte（細胞）　骨細胞。被自身基質包埋的 osteoblast，住在 lacuna，經 canaliculi 連通，感知力學訊號。
記憶提示

-blast 是動工中，-cyte 是定居後。定居後的骨細胞不再砌牆，但軟骨的 -cyte 仍在做工。

osteoclast
oste-（骨）+ -clast（打碎，源自 klastos）　破骨細胞。來自單核球系，多核，負責骨吸收。
記憶提示

clast＝break，跟 iconoclast（打破偶像者）同源。出身跟另外兩種骨細胞不同，這點常考。

osteoprogenitor cell
pro-（在前）+ genitor（產生者）　骨原前驅細胞。介於間質細胞與成骨細胞之間，存在於骨膜 cambium layer。
記憶提示

「祖先細胞」。它的存在就是為了證明 mesenchymal 不能直接跳到 osteocyte。

intramembranous ossification
intra-（在內）+ membran-（膜）+ -ous　膜內骨化。由纖維結締組織膜直接成骨，見於顱骨、鎖骨。
記憶提示

字面就是「在膜裡面」。膜＝membrane，不是 cartilage——名字沒有軟骨，過程也沒有軟骨。

endochondral ossification
endo-（在內）+ chondr-（軟骨）+ -al　軟骨內骨化。先做 hyaline cartilage 模型再置換成骨，見於長骨。
記憶提示

chondr- 出現就跟軟骨有關。字面「在軟骨之內」＝在軟骨模型裡面把骨長出來。

ossification center
oss-（骨，拉丁 os）+ -ification（化）　骨化中心。初級位於骨幹中央，次級位於骨骺。
記憶提示

初級在中間、次級在兩端；先中央後兩端，順序不可顛倒。

periosteum
peri-（周圍）+ oste-（骨）+ -um　骨膜。內層 cambium layer 含 osteoprogenitor，主司骨生長與修復。
記憶提示

peri-＝周圍，比較 pericardium（心包）、perichondrium（軟骨膜）。

perichondrium
peri-（周圍）+ chondr-（軟骨）　軟骨膜。可分化出 chondroblast；纖維軟骨缺乏它。
記憶提示

三型軟骨中唯一沒有軟骨膜的是 fibrocartilage，這是 113 年第 63 題的答案。

lamellar bone
lamella（薄板、薄層）　板層骨。collagen 纖維平行成層，構成所有成熟骨。
記憶提示

lamella 就是「薄片」，跟 laminate（層壓板）同源。像書頁一層層疊。

woven bone
weave（編織）　編織骨。纖維隨機交織，見於胎兒骨、骨折癒合早期。
記憶提示

「編織」＝亂中有序但不整齊，趕工的產物，之後會被改建成 lamellar。

trabecular bone
trabecula（小樑）　骨小梁／海綿骨。不規則網狀，內含骨髓，具造血功能。
記憶提示

trabecula 拉丁文是「小橫樑」。想像網狀鷹架，空隙裡塞著骨髓。

hydroxyapatite
hydroxy-（氫氧基）+ apatite（磷灰石）　Ca₁₀(PO₄)₆(OH)₂，骨的主要礦物質。
記憶提示

考點只有一句：骨的礦物是氫氧磷灰石，不是純鈣。

ARF cycle
Activation / Resorption / Reversal / Formation 的縮寫　骨重塑循環。
記憶提示

縮寫只取 A、R、F，中間的 Reversal 容易被漏掉——但選項常靠它做文章。四拍：叫醒、啃掉、交接、填回。

resorption
re-（回）+ sorb（吸收）　骨吸收。破骨細胞分解骨基質、釋出鈣質。
記憶提示

不是 absorption（吸收進來）而是 resorption（把自己的組織收回去）。

chondrogenesis
chondr-（軟骨）+ -genesis（生成）　軟骨生成。
記憶提示

-genesis 系列：osteogenesis 成骨、angiogenesis 血管新生、hematopoiesis 造血。

hyaline cartilage
hyalos（希臘文：玻璃）　透明軟骨。最常見，見於關節面、肋末端、生長板、氣管。
記憶提示

hyalo-＝玻璃，比較 hyaluronic acid（玻尿酸）。外觀半透明如毛玻璃。

fibrocartilage
fibro-（纖維）+ cartilage　纖維軟骨。type I collagen 為主、耐壓、無軟骨膜；見於椎間盤、恥骨聯合、半月板。
記憶提示

名字有 fibro 但不是膜內骨化的來源——112 年第 61 題就靠這個字設陷阱。

elastic cartilage
elastic（有彈性的）　彈性軟骨。富含彈性纖維，見於外耳、會厭。
記憶提示

捏一下自己的耳朵——會彈回來，所以是 elastic，不是 hyaline。連兩年考。

avascular
a-（無）+ vascular（血管的）　無血管的。軟骨的核心特性。
記憶提示

無血管 → 靠擴散 → 修復慢。這條因果鏈可以直接推出好幾個選項的對錯。

ovariectomy
ovari-（卵巢）+ -ectomy（切除）　去卵巢術。建立停經後骨質疏鬆動物模式的標準方法。
記憶提示

-ectomy＝切除，比較 appendectomy（闌尾切除）。切掉雌激素來源＝模擬停經。

glucocorticoid
gluco-（糖）+ cortic-（皮質）+ -oid　糖皮質素。長期過量導致骨質疏鬆，也用於誘發動物模式。
記憶提示

類固醇抑制成骨、促進骨吸收——臨床上的類固醇性骨鬆與實驗模型是同一個機轉。

grip strength test / rota-rod test
grip（抓握）／rota（旋轉）+ rod（桿）　抓握力測試＝肌力與神經肌肉功能；轉棒測試＝動作協調。
記憶提示

rota- 就是「轉」（rotate）——會轉的那個測協調；用手抓的那個測肌力。
