三年九題，只有兩個考點。六題考 YCL 讀片法的五字訣 CNRMT——而且三年用的是同一組四個選項（肩的鈣化、肘的脫位、橈骨過彎、多一節指骨），只是每年問不同的字母。剩下三題問腕部特殊投影看得到哪幾塊骨：carpal tunnel view 看不到掌骨、側面投影沒有一塊叫 cuboid（那是腳的）。

一、CNRMT：五個字母各問一個問題

故事

林老師的讀片法叫 YCL method，五個字母 C-N-R-M-T，像對一群人點名：

C — Category（種類）：這裡該有的骨頭有沒有少一種？有沒有不該出現的東西——異物、金屬植入物、軟組織裡的鈣化？
N — Number（數量）：某種骨頭的數目對不對？多一節指骨、少一塊腕骨。
R — Relation（相對位置）：骨頭之間站的位置對不對？脫位、內翻外翻、關節腔太寬太窄。
M — Morphology（形態）：骨頭本身的形狀與尺寸對不對？橈骨過度彎曲、變短、變粗。
T — Texture（質地）：骨頭的密度對不對？骨折線、變白（硬化）、變黑（溶骨）。

三年的考題全用同一組四個例子：

(A) 肩 AP 片上大結節處一個鈣化病灶 → Category（軟組織裡出現了不該有的東西）
(B) 肘側位片上橈骨與尺骨脫位 → Relation
(C) 前臂 AP 片上橈骨過度彎曲 → Morphology
(D) 手 AP 片上多了一組中節與遠節指骨 → Number

111 年問 R 和 M、112 年問 C 和 N、113 年問 M——四個選項一字不差，只換題幹的字母。113 年另出一題問「哪個不屬於 Texture」：骨折線、變白的月狀骨、溶骨病灶都是密度問題；金屬植入物是 Category。

回到現實

詳解原文（112 第 60 題）:「(A):category,看骨頭種類有沒有異常:有沒有多一整或少一種、有沒有出現異物。(B):relation,看骨頭之間的相對位置有沒有問題(排列:是否有內翻或外翻。關節的空間:是否有比較寬或窄)。(C):morphology,看骨頭型態有沒有問題，如:形狀、尺寸。(D):number:看某種骨頭數量有沒有問題」

詳解原文（113 第 72 題）:「金屬植入物屬於Category」

五字母＋固定例子：

C 種類／異物 → 大結節鈣化、金屬植入物
N 數量 → 多一組中節與遠節指骨
R 相對位置 → 橈尺骨脫位
M 形態 → 橈骨過度彎曲
T 質地（密度）→ 骨折線、月狀骨變白、溶骨病灶

注意一個小分歧：112 年第 59 題以「大結節鈣化＝Category」為正確答案，但 113 年第 71 題的學生詳解寫「鈣化為 Texture」。以正式答案為準：鈣化與金屬植入物一樣，都是「出現了不該有的東西」，歸 Category；Texture 指的是骨頭本身密度的改變。113 年那題正解是 (C) Morphology，不受這個分歧影響。

二、腕部特殊投影：看得到誰、看不到誰

故事

腕隧道是掌側腕骨圍成的一條溝。要在 X 光上看它，得把手腕用力往後折、X 光從掌根方向沿著隧道的軸線射進去——這叫 carpal tunnel view。

從這個角度，圍成隧道的骨頭會排成一個弧形露出來：鉤骨的鉤（hook of hamate）、豌豆骨、頭狀骨、舟狀骨、大多角骨。這五個是「主要看得到的構造」。

掌骨不在裡面——它在隧道的遠端，不構成隧道的邊緣。111 與 112 年同一題，答案都是掌骨。

113 年換考側面投影：手部 lateral view 看得到頭狀骨、大多角骨、豌豆骨、舟狀骨、月狀骨。選項裡塞了一個 cuboid（骰骨）——那是腳的骨頭，八塊腕骨裡沒有它。詳解自己說「送分題」。

回到現實

詳解原文（112）:「在Carpel tunnel view中比較能看到：trapezium, scaphoid, capitate, hamate,pisiform」

詳解原文（113）:「送分題，8塊腕骨沒有一塊叫 Cuboid　看一下真正的lateral view 可以看到什麼吧！1. Capitate 2. Trapezium 3. Pisiform 4. Scaphoid 5. Lunate」

Carpal tunnel view 主要構造：鉤骨鉤、豌豆骨、頭狀骨、舟狀骨、大多角骨。不含掌骨。

Hand lateral view 看得到：頭狀骨、大多角骨、豌豆骨、舟狀骨、月狀骨。Cuboid 是足部的骨頭。

兩題的解法都是找那個「根本不是腕骨」或「不在隧道邊緣」的選項——掌骨是手的但不圍隧道；骰骨連手都不是。

三、考前速記

  • CNRMT ＝ Category 種類與異物、Number 數量、Relation 相對位置、Morphology 形態、Texture 質地。
  • 大結節鈣化 → Category；金屬植入物 → Category。「出現不該有的東西」都是 C。
  • 多一組指骨 → Number。
  • 橈尺骨脫位 → Relation。內翻外翻、關節腔寬窄也是 R。
  • 橈骨過度彎曲 → Morphology。形狀、尺寸都是 M。
  • 骨折線、變白（硬化）、溶骨 → Texture。骨頭本身的密度。
  • 三年同一組四個選項，只換題幹字母——把四個例子各配一個字母背死。
  • Carpal tunnel view 五塊：鉤骨鉤、豌豆骨、頭狀骨、舟狀骨、大多角骨。掌骨不在。
  • Hand lateral view 五塊：頭狀骨、大多角骨、豌豆骨、舟狀骨、月狀骨。Cuboid 是腳的。
  • 113 年詳解把鈣化寫成 Texture，與 112 年正式答案（Category）不同——以正式答案為準。

四、單字表

YCL method (CNRMT)
林育全老師的讀片口訣　五步驟判讀骨骼 X 光：Category、Number、Relation、Morphology、Texture。
記憶提示

像點名：有沒有不該來的、人數、站位、長相、膚色。

Category
category＝類別　種類：該有的骨頭少了一種、或出現異物（金屬、鈣化）。
記憶提示

鈣化與金屬植入物都歸這裡。

Number
number＝數目　數量：某種骨頭多了或少了。
記憶提示

多一組中節遠節指骨。

Relation
relation＝關係　相對位置：脫位、排列（內翻外翻）、關節腔寬窄。
記憶提示

橈尺骨脫位。

Morphology
morpho-（形）+ -logy　形態：骨頭本身的形狀與尺寸。
記憶提示

橈骨過度彎曲。

Texture
texture＝質地　質地：骨頭的密度——骨折線、硬化變白、溶骨變黑。
記憶提示

三個都是骨頭本身的密度，金屬不算。

over-bowing
bow＝弓　過度彎曲。長骨呈弓形變形，屬 Morphology。
記憶提示

三年固定的 M 例子。

osteolytic lesion
osteo-（骨）+ lysis（溶解）　溶骨病灶，X 光上變黑，屬 Texture。
記憶提示

密度減少；變白是密度增加，兩者都是 T。

carpal tunnel view
carpal＝腕的；tunnel＝隧道　腕隧道投影。腕背屈、X 光沿隧道軸射入。
記憶提示

看到鉤骨鉤、豌豆骨、頭狀骨、舟狀骨、大多角骨；掌骨不在。

hook of hamate
hamate＝鉤狀的　鉤骨鉤，腕隧道尺側壁，carpal tunnel view 的主要構造。
記憶提示

這個投影就是為了看它與豌豆骨。

pisiform
拉丁 pisum＝豌豆　豌豆骨，腕隧道尺側的小骨。
記憶提示

兩種投影都看得到它。

trapezium
希臘 trapezion＝梯形　大多角骨，腕隧道橈側壁。
記憶提示

兩種投影都看得到它。

cuboid
cube＝立方體　骰骨，足部的跗骨之一。
記憶提示

八塊腕骨沒有它——113 年的送分題。

metacarpal
meta-（之後）+ carpal（腕）　掌骨，腕骨遠端的五根長骨。
記憶提示

不圍成腕隧道，所以不是 carpal tunnel view 的主要構造。
